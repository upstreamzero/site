Recommendation set formation studies the opening move: the set of vendors an
evaluator surfaces for a broad category question, before a buyer has stated any
specific requirement. The opening set is the baseline every later requirement
acts on.

The core question is who appears in the opening set and what governs
membership. What remains open is how stable the opening set is across runs and
evaluators.
